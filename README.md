# ARMOSpec

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Useful for multiple Raspberry Pi units that run 24/7 and break down. It records the conditions at a
given time: CPU information, Raspberry Pi hardware, firmware and software information, and the SD card
registers (CID, CSD, SCR and type).

    ./ARMOSpec.sh
